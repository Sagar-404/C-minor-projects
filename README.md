## 🛠️ Getting Started

### Prerequisites
To run these projects, you need a **C compiler** installed on your system:
*   **GCC** (windows)

### Compilation & Running
1. Clone the repository:
   ```bash
   git clone https://github.com/Sagar-404/C-minor-projects.git
   ```
2. Compile the C file:
   ```bash
   gcc main.c -o program
   ```
3. Run the executable:
   ```bash
   ./program
   ```
